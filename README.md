# Copilot Studio Test

This repository is a simple test project for exploring GitHub + Copilot Studio workflows.

## Purpose

- Validate repository setup
- Test file creation and editing
- Serve as a basic sandbox for automation and experimentation

## Getting Started

1. Clone the repository.
2. Open the project in your editor.
3. Add or modify files as needed for testing.

## Example

```bash
git clone https://github.com/zeynal-code/copilot-studio-test.git
cd copilot-studio-test
```
